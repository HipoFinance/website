title: 'Brand Kit'
---

Brand kit Hipo dirancang untuk mitra dan kolaborator kami. Di dalamnya ada logo Hipo, logotype, dan dua lockup resmi — masing-masing dalam SVG dan PNG, dengan versi untuk latar belakang gelap dan versi untuk latar terang — beserta token mark hGRAM dan HPO, ikon aplikasi, serta palet warna merek. README di dalamnya menjelaskan file mana yang dipakai di mana, berapa ruang kosong di sekitar logo, dan nilai-nilai warnanya.
