## O que é o dashboard do Hipo no Dune?

O <a href="https://dune.com/hipofinance/stake-gram-on-ton-with-hipo-liquid-staking-with-top-apy" target="_blank" rel="noopener">dashboard do Hipo no Dune</a> é o nosso dashboard público de análises no [Dune](https://dune.com/), uma plataforma bastante usada para explorar dados de blockchain.

Tudo o que acontece na blockchain TON — cada staking, cada unstake e cada transferência de token — é público. O Dune reúne esses dados brutos da blockchain, organiza tudo em tabelas fáceis de ler e permite que qualquer pessoa monte gráficos em cima deles. Nosso dashboard usa esses dados para mostrar o que realmente acontece dentro do Hipo, direto da própria blockchain.

Você não precisa de conta nem de carteira para ver — basta abrir o link no navegador.

## Por que o Dune além do Hipo Stats?

Criamos nosso dashboard no Dune como um **complemento** ao dashboard [Hipo Stats](/docs/introduction/hipo-stats/) ([stats.hipo.finance](https://stats.hipo.finance/)) — não como substituto. Os dois têm finalidades diferentes:

- **O Hipo Stats** é a sua visão rápida do dia a dia: o preço atual do hGRAM, o TVL, o APY e outros números importantes de relance, alimentados pelos nossos próprios sistemas de monitoramento.
- **O dashboard do Dune** é para análises nativas de blockchain: atividade do protocolo ao longo do tempo, tendências de carteiras e holders, fluxos de tokens, uso em DeFi e comparações com o ecossistema TON como um todo — tudo construído sobre dados on-chain indexados.

Como o Dune lê diretamente da blockchain pública, ele também é uma ferramenta de transparência. Você não precisa acreditar na nossa palavra sobre os números: os dados por trás de cada gráfico vêm da própria TON, e qualquer pessoa pode inspecionar as consultas que os produzem. Isso faz do Dune uma opção ideal para membros da comunidade, pesquisadores e analistas de DeFi que querem verificar as coisas de forma independente ou aprofundar além de uma página de resumo.

## Compartilhar e construir em cima

Uma das melhores partes do Dune é que ele foi feito para ser compartilhado. Você pode enviar a qualquer pessoa um link para o dashboard ou para um gráfico específico, incorporar gráficos em artigos ou posts e — se você gosta de dados — até copiar ("fazer um fork") das nossas consultas no Dune para montar sua própria análise do Hipo. As consultas e os gráficos por trás do dashboard também são de código aberto: nós os mantemos no repositório <a href="https://github.com/HipoFinance/dune" target="_blank" rel="noopener">HipoFinance/dune</a> no GitHub, então você pode revisar como cada número é calculado ou sugerir melhorias por lá.

Se houver um gráfico ou uma métrica que você gostaria de ver por lá, avise a gente nos nossos canais sociais. O retorno da comunidade orienta o que acompanhamos.
