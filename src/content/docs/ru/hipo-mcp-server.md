### Что такое Hipo MCP Server?

Hipo MCP Server — небольшой сервис с открытым исходным кодом, который даёт ИИ-ассистентам доступ к данным, связанным с Hipo, включая информацию о стейкинге GRAM и другие темы. Он работает по [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) — открытому стандарту подключения ИИ-клиентов к внешним данным, поэтому любой MCP-совместимый клиент — Claude, Claude Code, Cursor и другие — может обращаться к документации Hipo и запрашивать живые ончейн-показатели, а не угадывать по памяти.

После подключения ваш ассистент сможет отвечать на вопросы вроде:

- _Какой сейчас курс hGRAM/GRAM и какую APY это подразумевает?_
- _Сколько GRAM сейчас находится в стейкинге в Hipo?_
- _Когда заканчивается текущий раунд валидации и когда мой отложенный депозит выпустит hGRAM?_
- _Какой баланс hGRAM у этого адреса и сколько он стоит в GRAM?_
- _Какую комиссию за газ нужно приложить к депозиту?_

Ответы берутся из геттеров смарт-контрактов Hipo в TON, а не из обучающих данных модели, поэтому они актуальны на момент вашего вопроса.

Сервер работает строго в режиме **только для чтения**. Он не хранит ключей, ничего не подписывает и не отправляет сообщений в блокчейн. Он может смотреть, но никогда не может перемещать ваши средства — его подключение не даёт никому возможности стейкать, выводить из стейкинга или переводить что-либо от вашего имени.

### Подключение

#### Размещённый сервер (рекомендуется)

Hipo поддерживает публичный экземпляр. Направьте свой MCP-клиент на:

```
https://mcp.hipo.finance/mcp
```

В [Claude Code](https://claude.com/claude-code) достаточно одной команды:

```sh
claude mcp add --transport http hipo https://mcp.hipo.finance/mcp
```

Это регистрирует сервер для текущего проекта. Чтобы он был доступен из всех проектов, передайте `-s user` — здесь `user` является литеральным ключевым словом области действия, а не заменителем вашего имени пользователя:

```sh
claude mcp add -s user --transport http hipo https://mcp.hipo.finance/mcp
```

В любом случае используйте команду, а не правьте файл конфигурации вручную: Claude Code хранит свои MCP-серверы в собственной конфигурации, и блок `mcpServers`, добавленный в `settings.json`, игнорируется. Выполните `claude mcp list`, чтобы убедиться, что сервер подключён, и затем перезапустите Claude Code — серверы подключаются при запуске, поэтому только что добавленный сервер недоступен в уже запущенной сессии.

Другие клиенты настраиваются через JSON-файл (Claude Desktop, Cursor и большинство остальных) и принимают запись такого вида:

```json
{
  "mcpServers": {
    "hipo": {
      "type": "http",
      "url": "https://mcp.hipo.finance/mcp"
    }
  }
}
```

#### Локальный запуск

Если вы предпочитаете запускать сервер самостоятельно, он опубликован в npm как [`@hipo-finance/mcp`](https://www.npmjs.com/package/@hipo-finance/mcp) и работает через stdio. Для этого нужен Node.js 20 или новее:

```sh
claude mcp add hipo -- npx -y @hipo-finance/mcp
```

Здесь действует тот же совет — добавляйте сервер командой, а не правкой файла вручную. Для других клиентов запись в JSON-конфигурации такая:

```json
{
  "mcpServers": {
    "hipo": {
      "command": "npx",
      "args": ["-y", "@hipo-finance/mcp"]
    }
  }
}
```

### Инструменты

Вот вопросы, на которые сервер умеет отвечать. Ваш ИИ-клиент сам выбирает нужный инструмент — вы спрашиваете обычным языком.

| Инструмент           | Что возвращает                                                                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `get_exchange_rate`  | Текущий курс hGRAM↔GRAM, общий объём GRAM в стейкинге, предложение hGRAM и недавнюю APY, выведенную из ончейн-обновлений курса                |
| `get_treasury_state` | Итоги по казне: TVL в GRAM, предложение hGRAM, ожидающие депозиты и выводы, активные участия в раундах, флаг остановки и параметры управления |
| `get_round_timing`   | Тайминг раундов валидации: границы текущего и следующего раунда, окно участия в выборах и то, как долго стейки остаются замороженными         |
| `get_fees`           | Текущие комиссии за газ для депозита, вывода из стейкинга и запросов займа                                                                    |
| `get_wallet_status`  | Баланс hGRAM указанного адреса, его стоимость в GRAM и все ожидающие стейки или выводы                                                        |
| `get_reward_history` | Историю наград за стейкинг GRAM указанного адреса по раундам, включая уровень в Hipo Club и награды в HPO                                     |
| `get_participation`  | Участие Hipo в раунде валидации: состояние, число займов, итоги и время высвобождения стейка                                                  |
| `get_loan_info`      | Контракт займа заёмщика за раунд: адрес, состояние развёртывания, баланс и стороны                                                            |
| `get_max_punishment` | Максимальный штраф, который протокол может применить для заданного стейка валидатора                                                          |

Первые четыре инструмента не требуют никаких входных данных. `get_wallet_status`, `get_reward_history` и `get_loan_info` принимают адрес TON — собственный адрес владельца или заёмщика, а не адрес его жетон-кошелька, — а `get_max_punishment` принимает сумму стейка в GRAM. `get_participation` и `get_loan_info` также принимают время начала раунда, но оно необязательно: опустите его, и они сообщат о текущем раунде.

Каждый ответ содержит одно и то же напоминание: инструменты возвращают живые данные протокола, а не финансовый совет; значения меняются каждый раунд валидации, и никакая доходность не гарантирована.

### Ресурсы документации

Помимо живых данных, сервер предоставляет технические документы Hipo в виде MCP-ресурсов, загружаемых из их канонических публичных источников, поэтому они всегда актуальны:

| Ресурс                     | Содержимое                                                                                      |
| -------------------------- | ----------------------------------------------------------------------------------------------- |
| `hipo://docs/overview`     | README репозитория смарт-контрактов: краткое описание протокола и адреса развёрнутых контрактов |
| `hipo://docs/architecture` | Контракты, конечный автомат раунда валидации и инварианты протокола                             |
| `hipo://docs/integration`  | Схемы сообщений и руководство по интеграции для кошельков и других протоколов                   |
| `hipo://docs/schema`       | Полные TL-B-схемы всех контрактов Hipo                                                          |
| `hipo://docs/knowledge`    | Курируемая база знаний Hipo ([llms.txt](https://hipo.finance/llms.txt))                         |

### Пример

Вызов `get_exchange_rate` возвращает обычный JSON. Числа меняются каждый раунд, поэтому воспринимайте это как форму ответа, а не как актуальные значения:

```json
{
  "oneHgramInGram": "1.143623345",
  "oneGramInHgram": "0.874413769",
  "totalCoinsGram": "2501952.200844389",
  "totalTokensHgram": "2187741.455006677",
  "recentApy": "15.59%",
  "apyNote": "APY is derived from the last on-chain rate update (current_rate / previous_rate compounded to a year). Rewards accrue in the exchange rate: hGRAM becomes worth more GRAM over time; there is no separate claim.",
  "disclaimer": "Live protocol data, not financial advice. Values change every validation round and no returns are guaranteed."
}
```

Сервер никогда не переопределяет математику протокола. Каждое число выше берётся из геттера контракта, а источником истины для развёрнутых адресов является репозиторий контрактов.

### Самостоятельный хостинг

Сервер распространяется под лицензией MIT и живёт по адресу [github.com/HipoFinance/mcp](https://github.com/HipoFinance/mcp). Он поставляется с двумя транспортами — `stdio` для локальных клиентов и streamable HTTP для размещённого развёртывания — и Dockerfile:

```sh
docker build -t hipo-mcp .
docker run -p 3000:3000 -e TONCENTER_API_KEY=... hipo-mcp
```

Вся конфигурация необязательна; по умолчанию используется основная сеть (мейннет) через публичный API toncenter.

| Переменная окружения       | По умолчанию                           | Назначение                                                                                                                |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `HIPO_NETWORK`             | `mainnet`                              | `mainnet` или `testnet`                                                                                                   |
| `TONCENTER_ENDPOINT`       | `https://toncenter.com/api/v2/jsonRPC` | Конечная точка TON HTTP API                                                                                               |
| `TONCENTER_API_KEY`        | _(нет)_                                | API-ключ toncenter; без него действует публичный лимит запросов, а ограниченные по частоте вызовы повторяются с задержкой |
| `TONCENTER_API_KEY_FILE`   | _(нет)_                                | Путь к файлу с API-ключом, например Docker-секрету; имеет приоритет над `TONCENTER_API_KEY`                               |
| `HIPO_STATE_CACHE_SECONDS` | `5`                                    | Как долго состояние казны, времена и комиссии кэшируются между вызовами инструментов                                      |
| `HIPO_DOCS_CACHE_SECONDS`  | `300`                                  | Как долго кэшируются ресурсы документации                                                                                 |
| `HIPO_REWARDS_API_BASE`    | `https://api.hipogang.io`              | Базовый URL API наград Hipo; задайте пустое значение, чтобы отключить `get_reward_history`                                |
| `PORT` / `HOST`            | `3000` / `0.0.0.0`                     | Только для HTTP-транспорта                                                                                                |
