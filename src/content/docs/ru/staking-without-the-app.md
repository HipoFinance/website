## Когда это нужно

Эта страница предназначена для кошельков, которые не могут подписывать транзакции dApp — мультисиг-кошельков и некоторых холодных кошельков. Всем остальным стоит использовать [приложение Hipo](/stake/), которое дешевле и показывает точную оценку перед подтверждением. Когда мультисиг-кошелёк подключается к приложению Hipo, нажатие «Стейкать» или «Анстейк» передаёт ордер прямо в приложение вашего кошелька; эти инструкции — запасной вариант на случай, если это не сработает.

## Стейкинг — комментарий «d»

Отправьте GRAM, который хотите застейкать, **плюс 0,1 GRAM** в качестве предоплаты за газ на казну Hipo:

```
EQCLyZHP4Xe8fpchQz76O-_RmUhaVc_9BAoGyJrwJrcbz2eZ
```

Установите текстовый комментарий транзакции ровно таким:

```
d
```

Комментарий должен быть строчными буквами, обычным текстом и незашифрованным. Предоплата взята с большим запасом — тратится лишь часть, а неиспользованная часть возвращается (см. [Комиссии и газ](/docs/fees-and-gas/)). hGRAM отправляется обратно на тот же адрес, с которого пришёл перевод.

## Полный вывод из стейкинга — комментарий «w»

Отправьте 0,1 GRAM на тот же адрес казны с текстовым комментарием:

```
w
```

Это выводит из стейкинга **весь** баланс hGRAM этого кошелька. Чтобы вывести только часть, используйте вместо этого необработанный ордер — см. следующий раздел. Вывод из стейкинга завершается по обычным правилам протокола, поэтому применяются сроки полного вывода из стейкинга — см. [Как работает вывод из стейкинга](/docs/introduction/how-does-hipo-work/unstaking/) и [Сколько времени занимает вывод из стейкинга?](/faq/#how-long-does-unstaking-take)

## Вывод части — необработанный ордер

Текстовый комментарий может запросить только всё сразу, потому что в нём негде указать сумму. Частичный вывод — это обычное сообщение с бинарным телом, поэтому нужен кошелёк или мультисиг, способный его отправить — multisig.ton.org называет это «Arbitrary order», и его форма принимает ровно три значения ниже.

Откройте [приложение Hipo](/unstake/) с подключённым мультисигом, введите сумму, которую хотите вывести из стейкинга, и нажмите «Анстейк». Приложение передаёт ордер в приложение вашего кошелька, которое создаёт его как мультисиг-запрос для утверждения остальными подписантами. **Перед подписанием убедитесь, что выбран именно ваш мультисиг** — ссылка не может выбрать его за вас. Если ни одно приложение кошелька не открылось, вместо этого приложение покажет три значения, чтобы вы могли составить ордер вручную:

- **Адрес назначения** — контракт вашего собственного hGRAM-кошелька. Это не казна: это контракт, который хранит ваш hGRAM и получен из адреса вашего мультисига. Проверьте его на Tonviewer перед подписанием; приложение даёт на него ссылку.
- **Сумма TON** — 0,1 GRAM, та же предоплата за газ, что и везде, возвращается за вычетом потраченной части.
- **Ордер BOC** — тело сообщения в формате base64.

Стоит знать две вещи. Этот ордер принимает только ваш собственный контракт hGRAM-кошелька, поэтому если он по ошибке подписан с другого кошелька, он просто отклоняется и ничего не сжигается — в отличие от комментария «w», который вывел бы из стейкинга любой баланс, оказавшийся на отправляющем кошельке. А если вы выбрали мгновенный курс, сумма, которую можно погасить мгновенно, меняется каждый раунд: подпишите быстро, либо выберите лучший курс для ордера, которому придётся ждать других подписей.

## Сжигание hGRAM через минтер

Вы также можете напрямую получить GRAM, сжигая hGRAM на [minter.ton.org](https://minter.ton.org/), используя мастер-адрес hGRAM (Parent):

```
EQDPdq8xjAhytYqfGSX8KcFWIReCufsB9Wdg0pLlYSO_h76w
```

После сжигания вы получаете GRAM по текущему курсу погашения. Адрес parent может измениться при обновлениях протокола — сначала проверьте [Контракты и аудиты](/docs/contracts-and-audits/).

## Или обмен на DEX

Пулы hGRAM существуют на DeDust, STON.fi, TONCO, GroypFi и swap.coffee — актуальный список на странице [DeFi](/defi/). Применяются комиссии за обмен и влияние на цену.

## Перед отправкой

- Проверяйте адрес казны по странице [Контракты и аудиты](/docs/contracts-and-audits/) — никогда не доверяйте адресу из пересланного сообщения; см. [Осведомлённость о фишинге](/docs/security/phishing-awareness-and-prevention/).
- Комментарий должен быть обычным текстом, ровно `d` или `w`.
- Перевод без комментария или с неверным комментарием не считается запросом на стейкинг или вывод из стейкинга.
- Для необработанного ордера проверьте, что адрес назначения — это ваш собственный контракт hGRAM-кошелька, а не адрес откуда-то ещё.
