## Когда это нужно

Эта страница предназначена для кошельков, которые не могут подписывать транзакции dApp — мультисиг-кошельков и некоторых холодных кошельков. Всем остальным стоит использовать [приложение Hipo](/stake/), которое дешевле и показывает точную оценку перед подтверждением. Когда мультисиг-кошелёк подключается к приложению Hipo, приложение показывает те же самые инструкции с адресом казны, готовым для копирования.

## Стейкинг — комментарий «d»

Отправьте GRAM, который хотите застейкать, **плюс 0,1 GRAM** в качестве предоплаты за газ на казну Hipo:

```
EQCLyZHP4Xe8fpchQz76O-_RmUhaVc_9BAoGyJrwJrcbz2eZ
```

Установите текстовый комментарий транзакции ровно таким:

```
d
```

Комментарий должен быть строчными буквами, обычным текстом и незашифрованным. Предоплата взята с большим запасом — тратится лишь часть, а неиспользованная часть возвращается (см. [Комиссии и газ](/docs/fees-and-gas/)). hGRAM отправляется обратно на тот же адрес, с которого пришёл перевод.

## Полный вывод из стейкинга — комментарий «w»

Отправьте 0,1 GRAM на тот же адрес казны с текстовым комментарием:

```
w
```

Это выводит из стейкинга **весь** баланс hGRAM этого кошелька — частичная сумма невозможна. Вывод из стейкинга завершается по обычным правилам протокола, поэтому применяются сроки полного вывода из стейкинга — см. [Как работает вывод из стейкинга](/docs/introduction/how-does-hipo-work/unstaking/) и [Сколько времени занимает вывод из стейкинга?](/faq/#how-long-does-unstaking-take)

## Сжигание hGRAM через минтер

Вы также можете напрямую получить GRAM, сжигая hGRAM на [minter.ton.org](https://minter.ton.org/), используя мастер-адрес hGRAM (Parent):

```
EQDPdq8xjAhytYqfGSX8KcFWIReCufsB9Wdg0pLlYSO_h76w
```

После сжигания вы получаете GRAM по текущему курсу погашения. Адрес parent может измениться при обновлениях протокола — сначала проверьте [Контракты и аудиты](/docs/contracts-and-audits/).

## Или обмен на DEX

Пулы hGRAM существуют на DeDust, STON.fi, TONCO, GroypFi и swap.coffee — актуальный список на странице [DeFi](/defi/). Применяются комиссии за обмен и влияние на цену.

## Перед отправкой

- Проверяйте адрес казны по странице [Контракты и аудиты](/docs/contracts-and-audits/) — никогда не доверяйте адресу из пересланного сообщения; см. [Осведомлённость о фишинге](/docs/security/phishing-awareness-and-prevention/).
- Комментарий должен быть обычным текстом, ровно `d` или `w`.
- Перевод без комментария или с неверным комментарием не считается запросом на стейкинг или вывод из стейкинга.
