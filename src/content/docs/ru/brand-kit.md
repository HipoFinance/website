Брендбук Hipo предназначен для наших партнёров и коллабораций. В нём есть логотип Hipo, логотайп и две официальные компоновки — каждая в форматах SVG и PNG, в версии для тёмного фона и для светлого, — а также знаки токенов hGRAM и HPO, иконки приложения и фирменная палитра. Файл README внутри объясняет, какой файл где применять, сколько свободного поля оставлять вокруг логотипа и какие использовать цвета.
