## ما هو Hipo MCP Server؟

Hipo MCP Server خدمة صغيرة مفتوحة المصدر تتيح للمساعدات الذكية الوصول إلى بيانات متعلقة بـ Hipo، بما في ذلك معلومات عن ستاكينغ GRAM ومواضيع أخرى. يتحدث الخادم [بروتوكول سياق النموذج](https://modelcontextprotocol.io/) (Model Context Protocol - MCP)، وهو معيار مفتوح لربط عملاء الذكاء الاصطناعي بالبيانات الخارجية، بحيث يمكن لأي عميل يدعم MCP — مثل Claude و Claude Code و Cursor وغيرها — البحث في وثائق Hipo والاستعلام عن الأرقام المباشرة على السلسلة بدلًا من التخمين من ذاكرته.

بعد الاتصال، يمكن لمساعدك الإجابة عن أسئلة مثل:

- _ما سعر صرف hGRAM/GRAM الحالي، وما معدل APY الذي يعنيه ذلك؟_
- _كم مقدار GRAM المودَع في الستاكينغ في Hipo الآن؟_
- _متى تنتهي جولة التحقق الحالية، ومتى سيُصدِر إيداعي المؤجَّل توكن hGRAM؟_
- _ما رصيد hGRAM لهذا العنوان، وكم تبلغ قيمته بـ GRAM؟_
- _ما رسوم الغاز التي ينبغي أن أرفقها بالإيداع؟_

تأتي الإجابات من دوال القراءة (getters) في العقود الذكية لـ Hipo على TON، لا من بيانات تدريب النموذج، لذا فهي محدَّثة لحظة سؤالك.

الخادم **للقراءة فقط** حصرًا. لا يحتفظ بأي مفاتيح، ولا يوقّع أي شيء، ولا يرسل أي رسائل إلى الشبكة. يمكنه أن يطّلع، لكنه لا يستطيع أبدًا تحريك أموالك — فربطه ليس طريقة لأي شخص لتنفيذ الستاكينغ أو إلغائه أو التحويل نيابة عنك.

## الاتصال

### الخادم المستضاف (موصى به)

تشغّل Hipo نسخة عامة. وجّه عميل MCP الخاص بك إلى:

```
https://mcp.hipo.finance/mcp
```

في [Claude Code](https://claude.com/product/claude-code)، يكفي أمر واحد:

```sh
claude mcp add --transport http hipo https://mcp.hipo.finance/mcp
```

يسجِّل هذا الأمر الخادم للمشروع الحالي. للوصول إليه من كل مشروع بدلًا من ذلك، أضف `-s user` — و`user` هنا كلمة مفتاحية حرفية للنطاق، وليست رمزًا نائبًا لاسم المستخدم الخاص بك:

```sh
claude mcp add -s user --transport http hipo https://mcp.hipo.finance/mcp
```

في كلتا الحالتين، استخدم الأمر بدلًا من تعديل ملف الإعداد يدويًا: يحتفظ Claude Code بخوادم MCP الخاصة به في إعداداته الخاصة، وأي كتلة `mcpServers` تُوضَع في `settings.json` يتم تجاهلها. شغّل `claude mcp list` للتأكد من اتصال الخادم، ثم أعد تشغيل Claude Code بعد ذلك — إذ تُوصَل الخوادم عند بدء التشغيل، لذا فإن الخادم المضاف حديثًا لا يكون متاحًا في جلسة قيد التشغيل بالفعل.

تُعدَّ العملاء الأخرى بملف JSON (Claude Desktop و Cursor ومعظم العملاء الأخرى) وتأخذ إدخالًا كهذا:

```json
{
  "mcpServers": {
    "hipo": {
      "type": "http",
      "url": "https://mcp.hipo.finance/mcp"
    }
  }
}
```

### تشغيله محليًا

إذا كنت تفضّل تشغيل الخادم بنفسك، فهو منشور على npm باسم [`@hipo-finance/mcp`](https://www.npmjs.com/package/@hipo-finance/mcp) ويتحدث عبر stdio. يتطلب هذا Node.js 20 أو أحدث:

```sh
claude mcp add hipo -- npx -y @hipo-finance/mcp
```

تنطبق النصيحة نفسها هنا — أضفه بالأمر، لا بتعديل ملف يدويًا. أما بالنسبة للعملاء الآخرين، فإدخال إعداد JSON هو:

```json
{
  "mcpServers": {
    "hipo": {
      "command": "npx",
      "args": ["-y", "@hipo-finance/mcp"]
    }
  }
}
```

## الأدوات

هذه هي الأسئلة التي يمكن للخادم الإجابة عنها. يختار عميل الذكاء الاصطناعي الخاص بك الأداة المناسبة تلقائيًا — وأنت تسأل بلغة طبيعية.

| الأداة               | ما تعيده                                                                                                                                       |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `get_exchange_rate`  | سعر التبادل الحالي بين hGRAM↔GRAM، إجمالي GRAM المودَع في الستاكينغ، معروض hGRAM، ومعدل APY الأخير المشتق من تحديثات السعر على السلسلة         |
| `get_treasury_state` | إجماليات الخزينة: TVL بـ GRAM، معروض hGRAM، الإيداعات وإلغاءات الستاكينغ المعلَّقة، المشاركات النشطة في الجولة، علامة الإيقاف، ومعطيات الحوكمة |
| `get_round_timing`   | توقيت جولة التحقق: حدود الجولة الحالية والتالية، نافذة المشاركة في الانتخابات، ومدة تجميد المبالغ المودَعة                                     |
| `get_fees`           | رسوم الغاز الحالية للإيداع وإلغاء الستاكينغ وطلبات القرض                                                                                       |
| `get_wallet_status`  | رصيد hGRAM لعنوان معيّن، وقيمته بـ GRAM، وأي مبالغ ستاكينغ أو إلغاء ستاكينغ معلَّقة                                                            |
| `get_reward_history` | سجل مكافآت ستاكينغ GRAM التاريخية لعنوان معيّن حسب الجولة، بما في ذلك مستوى Hipo Club ومكافآت HPO                                              |
| `get_participation`  | مشاركة Hipo في جولة تحقق: الحالة، عدد القروض، الإجماليات، ووقت الإفراج عن المبالغ المودَعة                                                     |
| `get_loan_info`      | عقد قرض المقترض لكل جولة: العنوان، حالة النشر، الرصيد، والأطراف                                                                                |
| `get_max_punishment` | أقصى عقوبة يمكن للبروتوكول تطبيقها على مبلغ فاليديتور معيّن                                                                                    |

لا تحتاج الأدوات الأربع الأولى إلى أي مدخلات على الإطلاق. تأخذ `get_wallet_status` و `get_reward_history` و `get_loan_info` عنوان TON — عنوان المالك أو المقترض نفسه، لا عنوان محفظة الجيتون الخاصة به — وتأخذ `get_max_punishment` مبلغًا مودَعًا بـ GRAM. كما تقبل `get_participation` و `get_loan_info` وقت بدء الجولة، لكنه اختياري: احذفه ليقدّما تقريرًا عن الجولة الحالية.

تحمل كل استجابة التذكير نفسه بأن الأدوات تعيد بيانات بروتوكول مباشرة، لا نصيحة مالية: القيم تتغيّر مع كل جولة تحقق ولا ضمان لأي عوائد.

## موارد الوثائق

إلى جانب البيانات المباشرة، يعرض الخادم مستندات Hipo التقنية كموارد MCP، تُجلَب من مواقعها العامة الرسمية بحيث تبقى محدَّثة دائمًا:

| المورد                     | المحتوى                                                                   |
| -------------------------- | ------------------------------------------------------------------------- |
| `hipo://docs/overview`     | ملف README لمستودع العقود الذكية: ملخص البروتوكول وعناوين العقود المنشورة |
| `hipo://docs/architecture` | العقود، آلة حالة جولة التحقق، وثوابت البروتوكول                           |
| `hipo://docs/integration`  | مخططات الرسائل ودليل التكامل للمحافظ والبروتوكولات الأخرى                 |
| `hipo://docs/schema`       | مخططات TL-B الكاملة لجميع عقود Hipo                                       |
| `hipo://docs/knowledge`    | قاعدة معرفة Hipo المنسَّقة ([llms.txt](https://hipo.finance/llms.txt))    |

## مثال

يُرجِع استدعاء `get_exchange_rate` كائن JSON عادي. تتغيّر الأرقام مع كل جولة، لذا تعامل معها كصيغة توضيحية لا كقيم حالية:

```json
{
  "oneHgramInGram": "1.143623345",
  "oneGramInHgram": "0.874413769",
  "totalCoinsGram": "2501952.200844389",
  "totalTokensHgram": "2187741.455006677",
  "recentApy": "15.59%",
  "apyNote": "APY is derived from the last on-chain rate update (current_rate / previous_rate compounded to a year). Rewards accrue in the exchange rate: hGRAM becomes worth more GRAM over time; there is no separate claim.",
  "disclaimer": "Live protocol data, not financial advice. Values change every validation round and no returns are guaranteed."
}
```

لا يعيد الخادم تنفيذ رياضيات البروتوكول أبدًا. يأتي كل رقم أعلاه من دالة قراءة في العقد، ومستودع العقود هو المرجع الرسمي لعناوين النشر.

## الاستضافة الذاتية

الخادم مرخَّص بموجب MIT ومتاح على [github.com/HipoFinance/mcp](https://github.com/HipoFinance/mcp). يوفّر وسيلتَي نقل — `stdio` للعملاء المحليين و HTTP القابل للبث للنشر المستضاف — إضافة إلى Dockerfile:

```sh
docker build -t hipo-mcp .
docker run -p 3000:3000 -e TONCENTER_API_KEY=... hipo-mcp
```

جميع الإعدادات اختيارية؛ تستهدف القيم الافتراضية الشبكة الرئيسية عبر واجهة toncenter العامة.

| متغيّر البيئة              | القيمة الافتراضية                      | الغرض                                                                                                              |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `HIPO_NETWORK`             | `mainnet`                              | `mainnet` أو `testnet`                                                                                             |
| `TONCENTER_ENDPOINT`       | `https://toncenter.com/api/v2/jsonRPC` | نقطة نهاية TON HTTP API                                                                                            |
| `TONCENTER_API_KEY`        | _(لا شيء)_                             | مفتاح API الخاص بـ toncenter؛ بدونه يُطبَّق الحد العام لمعدل الطلبات، وتُعاد محاولة الطلبات المحدودة بتأخير تصاعدي |
| `TONCENTER_API_KEY_FILE`   | _(لا شيء)_                             | مسار ملف يحتوي على مفتاح API، مثل سر Docker؛ له الأولوية على `TONCENTER_API_KEY`                                   |
| `HIPO_STATE_CACHE_SECONDS` | `5`                                    | مدة تخزين حالة الخزينة والأوقات والرسوم مؤقتًا بين استدعاءات الأدوات                                               |
| `HIPO_DOCS_CACHE_SECONDS`  | `300`                                  | مدة تخزين موارد الوثائق مؤقتًا                                                                                     |
| `HIPO_REWARDS_API_BASE`    | `https://api.hipogang.io`              | عنوان URL الأساسي لواجهة مكافآت Hipo؛ اتركه فارغًا لتعطيل `get_reward_history`                                     |
| `PORT` / `HOST`            | `3000` / `0.0.0.0`                     | لوسيلة النقل HTTP فقط                                                                                              |
