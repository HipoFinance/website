title: 'Brand Kit'
---

The Hipo brand kit is designed for our partners and collaborators. It holds the Hipo logo, the logotype and the two lockups — each in SVG and PNG, in a version for dark backgrounds and one for light — along with the hGRAM and HPO token marks, app icons and the brand palette. The README inside covers which file to use where, the clear space around the logo and the color values.
