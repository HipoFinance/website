### Hipo MCP Server क्या है?

Hipo MCP Server एक छोटी, ओपन-सोर्स सेवा है, जो AI असिस्टेंट को Hipo से जुड़े डेटा तक पहुँचने देती है — जिसमें GRAM स्टेकिंग और अन्य विषयों की जानकारी शामिल है। यह [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) बोलता है — AI क्लाइंट को बाहरी डेटा से जोड़ने का एक खुला मानक — इसलिए कोई भी MCP-सक्षम क्लाइंट — Claude, Claude Code, Cursor और अन्य — स्मृति से अनुमान लगाने के बजाय Hipo के दस्तावेज़ देख सकता है और लाइव ऑन-चेन आँकड़े क्वेरी कर सकता है।

कनेक्ट होने के बाद आपका असिस्टेंट ऐसे सवालों के जवाब दे सकता है:

- _मौजूदा hGRAM/GRAM विनिमय दर क्या है, और उससे कितना APY निकलता है?_
- _इस समय Hipo में कितना GRAM स्टेक किया हुआ है?_
- _मौजूदा वैलिडेशन राउंड कब खत्म होगा, और मेरा स्थगित डिपॉज़िट hGRAM कब मिंट करेगा?_
- _इस पते का hGRAM बैलेंस कितना है, और GRAM में उसका मूल्य क्या है?_
- _डिपॉज़िट के साथ मुझे कितनी गैस फ़ीस जोड़नी चाहिए?_

जवाब TON पर Hipo के स्मार्ट-कॉन्ट्रैक्ट गेटर्स से आते हैं, मॉडल के ट्रेनिंग डेटा से नहीं, इसलिए वे ठीक उसी पल तक के अद्यतन होते हैं जब आप पूछते हैं।

यह सर्वर सख़्ती से **केवल-पठन** है। इसके पास कोई कुंजी नहीं है, यह कुछ भी साइन नहीं करता, और ब्लॉकचेन पर कोई संदेश नहीं भेजता। यह देख सकता है, लेकिन आपकी निधि कभी नहीं हिला सकता — इसे कनेक्ट करना किसी के लिए आपकी ओर से स्टेक, अनस्टेक या ट्रांसफ़र करने का ज़रिया नहीं है।

### कनेक्ट करना

#### होस्टेड सर्वर (अनुशंसित)

Hipo एक सार्वजनिक इंस्टेंस चलाता है। अपने MCP क्लाइंट को यहाँ पॉइंट करें:

```
https://mcp.hipo.finance/mcp
```

[Claude Code](https://claude.com/product/claude-code) में एक कमांड काफ़ी है:

```sh
claude mcp add --transport http hipo https://mcp.hipo.finance/mcp
```

यह सर्वर को मौजूदा प्रोजेक्ट के लिए रजिस्टर करता है। इसके बजाय हर प्रोजेक्ट से इस तक पहुँचने के लिए `-s user` पास करें — यहाँ `user` एक शाब्दिक स्कोप कीवर्ड है, आपके अपने यूज़रनेम का प्लेसहोल्डर नहीं:

```sh
claude mcp add -s user --transport http hipo https://mcp.hipo.finance/mcp
```

दोनों ही मामलों में कॉन्फ़िगरेशन फ़ाइल हाथ से संपादित करने के बजाय कमांड का इस्तेमाल करें: Claude Code अपने MCP सर्वर अपनी ही कॉन्फ़िग में रखता है, और `settings.json` में डाला गया `mcpServers` ब्लॉक नज़रअंदाज़ कर दिया जाता है। सर्वर कनेक्ट हुआ है या नहीं, यह पुष्टि करने के लिए `claude mcp list` चलाएँ, और उसके बाद Claude Code को पुनः प्रारंभ करें — सर्वर स्टार्टअप पर कनेक्ट होते हैं, इसलिए नया जोड़ा गया सर्वर पहले से चल रहे सेशन में उपलब्ध नहीं होता।

अन्य क्लाइंट (Claude Desktop, Cursor और अधिकांश अन्य) एक JSON फ़ाइल से कॉन्फ़िगर होते हैं और इस तरह की एंट्री लेते हैं:

```json
{
  "mcpServers": {
    "hipo": {
      "type": "http",
      "url": "https://mcp.hipo.finance/mcp"
    }
  }
}
```

#### इसे लोकली चलाना

अगर आप सर्वर खुद चलाना चाहें, तो यह npm पर [`@hipo-finance/mcp`](https://www.npmjs.com/package/@hipo-finance/mcp) के रूप में प्रकाशित है और stdio बोलता है। इसके लिए Node.js 20 या नया चाहिए:

```sh
claude mcp add hipo -- npx -y @hipo-finance/mcp
```

यहाँ भी वही सलाह लागू होती है — इसे कमांड से जोड़ें, फ़ाइल हाथ से संपादित करके नहीं। अन्य क्लाइंट के लिए JSON कॉन्फ़िगरेशन एंट्री यह है:

```json
{
  "mcpServers": {
    "hipo": {
      "command": "npx",
      "args": ["-y", "@hipo-finance/mcp"]
    }
  }
}
```

### टूल

ये वे सवाल हैं जिनके जवाब सर्वर दे सकता है। आपका AI क्लाइंट खुद सही टूल चुन लेता है — आप बस सादी भाषा में पूछें।

| टूल                  | यह क्या लौटाता है                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `get_exchange_rate`  | मौजूदा hGRAM↔GRAM दर, कुल स्टेक किया हुआ GRAM, hGRAM सप्लाई, और ऑन-चेन दर अपडेट से निकाला गया हालिया APY                                    |
| `get_treasury_state` | ट्रेज़री के कुल आँकड़े: GRAM में TVL, hGRAM सप्लाई, लंबित डिपॉज़िट और अनस्टेक, सक्रिय राउंड भागीदारियाँ, हॉल्ट फ़्लैग, और गवर्नेंस पैरामीटर |
| `get_round_timing`   | वैलिडेशन राउंड की टाइमिंग: मौजूदा और अगले राउंड की सीमाएँ, इलेक्शन भागीदारी विंडो, और स्टेक कितनी देर फ़्रीज़ रहते हैं                      |
| `get_fees`           | डिपॉज़िट, अनस्टेक और लोन अनुरोधों के लिए मौजूदा गैस शुल्क                                                                                   |
| `get_wallet_status`  | किसी दिए गए पते का hGRAM बैलेंस, GRAM में उसका मूल्य, और कोई भी लंबित स्टेक या अनस्टेक                                                      |
| `get_reward_history` | किसी दिए गए पते के प्रति राउंड ऐतिहासिक GRAM स्टेकिंग रिवॉर्ड्स, Hipo Club लेवल और HPO रिवॉर्ड्स सहित                                       |
| `get_participation`  | किसी वैलिडेशन राउंड में Hipo की भागीदारी: स्थिति, लोन की संख्या, कुल योग, और स्टेक रिलीज़ का समय                                            |
| `get_loan_info`      | किसी उधारकर्ता का प्रति राउंड लोन कॉन्ट्रैक्ट: पता, डिप्लॉयमेंट स्थिति, बैलेंस, और पक्ष                                                     |
| `get_max_punishment` | किसी दिए गए वैलिडेटर स्टेक के लिए प्रोटोकॉल जो अधिकतम दंड लगा सकता है                                                                       |

पहले चार टूल को किसी इनपुट की ज़रूरत नहीं। `get_wallet_status`, `get_reward_history` और `get_loan_info` एक TON पता लेते हैं — मालिक या उधारकर्ता का अपना पता, उनके जेटन वॉलेट का पता नहीं — और `get_max_punishment` GRAM में स्टेक राशि लेता है। `get_participation` और `get_loan_info` राउंड का आरंभ समय भी स्वीकार करते हैं, लेकिन यह वैकल्पिक है: इसे छोड़ दें तो वे मौजूदा राउंड की रिपोर्ट देते हैं।

हर प्रतिक्रिया के साथ यही अनुस्मारक आता है कि टूल लाइव प्रोटोकॉल डेटा लौटाते हैं, वित्तीय सलाह नहीं: मान हर वैलिडेशन राउंड में बदलते हैं और किसी रिटर्न की गारंटी नहीं है।

### दस्तावेज़ संसाधन

लाइव डेटा के साथ-साथ सर्वर Hipo के तकनीकी दस्तावेज़ MCP संसाधनों के रूप में उपलब्ध कराता है, जो उनके आधिकारिक सार्वजनिक स्थानों से लाए जाते हैं ताकि वे हमेशा अद्यतन रहें:

| संसाधन                     | सामग्री                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| `hipo://docs/overview`     | स्मार्ट-कॉन्ट्रैक्ट रिपॉज़िटरी का README: प्रोटोकॉल सारांश और डिप्लॉय किए गए कॉन्ट्रैक्ट पते |
| `hipo://docs/architecture` | कॉन्ट्रैक्ट, वैलिडेशन-राउंड स्टेट मशीन, और प्रोटोकॉल इनवैरिएंट                               |
| `hipo://docs/integration`  | संदेश स्कीमा और वॉलेट तथा अन्य प्रोटोकॉल के लिए इंटीग्रेशन गाइड                              |
| `hipo://docs/schema`       | सभी Hipo कॉन्ट्रैक्ट के पूर्ण TL-B स्कीमा                                                    |
| `hipo://docs/knowledge`    | क्यूरेटेड Hipo नॉलेज बेस ([llms.txt](https://hipo.finance/llms.txt))                         |

### उदाहरण

`get_exchange_rate` को कॉल करने पर सादा JSON मिलता है। आँकड़े हर राउंड बदलते हैं, इसलिए इन्हें एक ढाँचा मानें, मौजूदा मान नहीं:

```json
{
  "oneHgramInGram": "1.143623345",
  "oneGramInHgram": "0.874413769",
  "totalCoinsGram": "2501952.200844389",
  "totalTokensHgram": "2187741.455006677",
  "recentApy": "15.59%",
  "apyNote": "APY is derived from the last on-chain rate update (current_rate / previous_rate compounded to a year). Rewards accrue in the exchange rate: hGRAM becomes worth more GRAM over time; there is no separate claim.",
  "disclaimer": "Live protocol data, not financial advice. Values change every validation round and no returns are guaranteed."
}
```

सर्वर कभी भी प्रोटोकॉल का गणित फिर से लागू नहीं करता। ऊपर का हर आँकड़ा किसी कॉन्ट्रैक्ट गेटर से आता है, और डिप्लॉय किए गए पतों के लिए कॉन्ट्रैक्ट रिपॉज़िटरी ही सत्य का स्रोत है।

### सेल्फ़-होस्टिंग

सर्वर MIT-लाइसेंस प्राप्त है और [github.com/HipoFinance/mcp](https://github.com/HipoFinance/mcp) पर उपलब्ध है। यह दो ट्रांसपोर्ट — लोकल क्लाइंट के लिए `stdio` और होस्टेड डिप्लॉयमेंट के लिए स्ट्रीमेबल HTTP — और एक Dockerfile के साथ आता है:

```sh
docker build -t hipo-mcp .
docker run -p 3000:3000 -e TONCENTER_API_KEY=... hipo-mcp
```

सारा कॉन्फ़िगरेशन वैकल्पिक है; डिफ़ॉल्ट सार्वजनिक toncenter API के ज़रिये मेननेट को लक्षित करते हैं।

| एनवायरनमेंट वेरिएबल        | डिफ़ॉल्ट                               | उद्देश्य                                                                                                                 |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `HIPO_NETWORK`             | `mainnet`                              | `mainnet` या `testnet`                                                                                                   |
| `TONCENTER_ENDPOINT`       | `https://toncenter.com/api/v2/jsonRPC` | TON HTTP API एंडपॉइंट                                                                                                    |
| `TONCENTER_API_KEY`        | _(कोई नहीं)_                           | toncenter API कुंजी; इसके बिना सार्वजनिक रेट लिमिट लागू होती है, और रेट-लिमिटेड कॉल बैकऑफ़ के साथ दोबारा आज़माए जाते हैं |
| `TONCENTER_API_KEY_FILE`   | _(कोई नहीं)_                           | API कुंजी वाली फ़ाइल का पथ, जैसे कोई Docker सीक्रेट; `TONCENTER_API_KEY` पर वरीयता पाता है                               |
| `HIPO_STATE_CACHE_SECONDS` | `5`                                    | टूल कॉल के बीच ट्रेज़री स्थिति, समय और शुल्क कितनी देर कैश रहते हैं                                                      |
| `HIPO_DOCS_CACHE_SECONDS`  | `300`                                  | दस्तावेज़ संसाधन कितनी देर कैश रहते हैं                                                                                  |
| `HIPO_REWARDS_API_BASE`    | `https://api.hipogang.io`              | Hipo रिवॉर्ड्स API का बेस URL; `get_reward_history` बंद करने के लिए इसे खाली सेट करें                                    |
| `PORT` / `HOST`            | `3000` / `0.0.0.0`                     | केवल HTTP ट्रांसपोर्ट के लिए                                                                                             |
