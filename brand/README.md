# Hipo Brand Kit

Everything here is the artwork hipo.finance itself renders, exported for partners, exchanges,
listing sites and anyone writing about Hipo. Use it as is — please don't redraw, recolor or
rebuild the marks.

Latest version: <https://hipo.finance/docs/brand-kit/>

## What's inside

```
Logo/            The hippo mark, the "Hipo" logotype and the two lockups, each on dark
                 and on light backgrounds (SVG + PNG)
Token Marks/     hGRAM and HPO, flat and 3D, plus the legacy hTON coin
                 (SVG + PNG at 256, 512, 1024)
App Icons/       favicon.ico and square PNG icons from 32 to 512
Colors/          Palette sheet, hipo-colors.css, hipo-colors.txt
```

The dark/light pairing applies to the logo, the logotype and the lockups. The token marks and the
app icons come in one colorway each — they carry their own disc, so they sit on any ground.

Every PNG has a transparent background except two, both deliberate:
`Logo/PNG/Hipo Logo on Dark Background 1000.png`, a ready-made tile for places that need a filled
square, and `Colors/Hipo Colors.png`, which is a reference sheet rather than an asset.

## Picking the right file

The mark is a cream body with dark linework, so it only reads on a dark ground. Anything on a
light ground takes the **(light backgrounds)** file, which is the same drawing as warm-dark line
art with a transparent body.

| Background          | Use                                         |
| ------------------- | ------------------------------------------- |
| Dark, or a photo    | `Hipo Logo`, `Hipo Horizontal Lockup`       |
| Cream, white, light | the matching `(light backgrounds)` file     |
| Either              | the token marks — they carry their own disc |

The logotype ships in three colorways: coral for most uses, cream on dark grounds, ink on light
ones. Both tokens ship flat and 3D — the flat coin is the one to use for jetton metadata, wallet
lists and anywhere it lands below about 64 px.

Prefer the SVG wherever the medium allows it — it stays sharp at any size and is a fraction of
the weight.

## Clear space and minimum size

Keep clear space around the logo equal to the height of the mascot's ear on every side, and
don't place type or other logos inside it.

The mark holds together down to about 32 px — below that the mouth and teeth close up. There is
no simplified small-size drawing (the app icons are this same mark at icon sizes), so give it
32 px or leave it out. The lockups need about 120 px of width; smaller than that the diamond dot
on the `i` disappears and you are better off with the mark alone.

## Please don't

- Recolor the mark, or fill the mascot body with anything but cream.
- Use the coral fill `#FF7E73` as text or an icon on a cream or white ground — use `#E0574B`.
- Stretch, rotate, add effects to, or crop the marks.
- Set "Hipo" in another typeface and pass it off as the logotype.
- Put the dark-background logo on a light ground, or the reverse.
- Imply a partnership, endorsement or listing that hasn't been agreed.

## Colors

The palette sheet in `Colors/` has the full list. The two that matter most:

- **Coral `#FF7E73`** — the brand accent, and the color of any solid coral fill on any ground.
- **Coral on light `#E0574B`** — the same coral as a foreground on cream or white, darkened so
  it keeps its contrast. Using `#FF7E73` there is the one color mistake we see most often.

## Typography

Hipo sets display type in **Fredoka** and body text in **Heebo**, both from Google Fonts under
the SIL Open Font License. They are not bundled here — download them from
<https://fonts.google.com/specimen/Fredoka> and <https://fonts.google.com/specimen/Heebo>.

The "Hipo" logotype is custom lettering, not a typeface. Use the supplied file.
